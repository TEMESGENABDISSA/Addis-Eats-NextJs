# Addis Eats

A Next.js (App Router) app for an Ethiopian food delivery menu. Built for CodeOps Day 36 to practise file-based routing.

## Features

- File-based routes: `/`, `/menu`, `/menu/[id]`, `/cart`, `/checkout`
- Dynamic dish pages using `[id]`
- Special states: `loading.tsx`, `error.tsx` and `not-found.tsx`
- Navigation with `next/link`
- Styled with Tailwind CSS

## Tech Stack

Next.js, React, TypeScript, Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000.
